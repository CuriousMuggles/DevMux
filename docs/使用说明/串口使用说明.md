# Serial 串口窗口与 Agent 接入

从「窗口 → Serial」选择本机或已连接从机，刷新 COM 列表并选择端口。默认参数为 921600/8/N/1、无流控。波特率可从常用下拉选择，也可在右侧输入自定义整数（1～12000000）。没有串口时只显示空列表，不打开任何端口。

打开后默认进入主终端区，与PowerShell/ADB shell共用标签及网格、水平、垂直、单屏布局。拖动标题栏可移出成为独立悬浮窗口，支持拖动、缩放、最小化、最大化；点击↙返回主终端区，保留原会话。最小化后点击标签恢复。手动关闭的窗口不被后台广播重新打开；主界面刷新按钮才恢复。不同 COM 可同时打开。同一 COM 参数相同时共用连接；参数不同时需先关闭原连接。

文本模式可在终端直接键入或使用底部输入框。Enter 发送，Ctrl+Enter 在输入框换行；选择 UTF-8/GBK/ASCII/Latin-1，末尾换行选择 CR/LF/CRLF/无。本地回显默认关闭，需要时开启。HEX 模式在底部输入完整字节对（例如 `00 FF 41 0D 0A`）并发送；HEX 不追加换行。收到的字节按十六进制显示；切换显示模式清屏，只影响显示，不影响字节游标或设备。

本机串口始终可用。要允许远程操作，在从机的 Serial 配置界面选择本机并开启「允许已连接主控远程使用本机串口」。该权限独立于 PowerShell、继电器和 DB。主控不能开启从机权限；权限撤销、解除配对、连接代次更新或节点停止会释放相关远程接入，本机接入保留。

GUI 与 Agent 共享输出，输入权独占。GUI 打开、接管或发送时可收回 Agent 输入权；Agent 不能抢 GUI 或另一 Agent。GUI「交还输入权」后 Agent 显式申请新代次；之前排队的旧输入仍拒绝。另一 GUI 已持权时，先在其窗口交还。关闭窗口只释放自己的接入；最后接入关闭时释放物理 COM。拔插后保持断开提示，手动关闭并重新打开；不自动连接、不重发。

## 快捷指令

点击串口工具栏「快捷指令」展开列表，选择指令集，点击「+」新增指令；右键指令可编辑或删除。支持指令集新建、改名、删除，至少保留一个指令集。名称和内容分别保存；文本指令按当前编码和换行发送，HEX指令按字节对发送且不追加换行。请先核对窗口当前格式。指令保存在运行程序旁的 `serial-commands.json`，与ADB的 `commands.json` 分开；本机和远程窗口共用此串口指令集。保存失败会显示原因。

## XMODEM发送与接收

点击「XMODEM…」展开传输面板，再按以下步骤操作：

1. 确认所选电脑与COM正确。参数需为8数据位，禁用XON/XOFF；沿用当前波特率、校验、停止位、硬件流控和DTR/RTS，不自动修改设备或执行烧写命令。
2. **发送**：先在设备端进入XMODEM接收模式，再选择发送分包128字节或1K，点击「发送文件…」选择本机文件。128字节按对端C/NAK自动使用CRC16或checksum；1K要求对端请求CRC。单文件最多64MiB；原文件不修改。
3. **接收**：先选择CRC16或Checksum，点击「接收文件」，再让设备进入XMODEM发送模式。128与1K包均可接收，界面显示实际接收字节及重试次数。
4. 成功接收后点击「保存接收文件」，在本机Windows另存为窗口选择新文件名；不覆盖已有文件。取消保存可再次保存。远程串口的协议和临时文件在从机执行，保存文件最终在操作者本机。
5. 观察准备、等待握手、传输、结束确认及成功/失败。可「取消传输」，运行时发送CAN；取消不能撤回设备已经收到的数据。准备与传输期间普通输入、快捷指令和接管暂停，其他GUI/Agent也不能抢占。

XMODEM没有文件名和精确原始长度。发送尾块以1A填充，接收保留填充字节，二进制文件请按已知长度或摘要核对，不能直接删除所有尾部1A。接收端结束时短暂等待重复EOT并再次确认；设备恢复提示符后保留该输出。超时与校验失败按协议有限重试，失败后重新操作前先核对设备状态。

请求回执未知时点击「查询 / 恢复准备」，沿用原requestId/transferId，不重新启动文件。上传块按offset与内容校验，后台协议重传与普通终端输入不重发是两种不同语义。关闭传输所属窗口、主界面断开、从机撤销串口权限/解除连接或程序停止会终止传输并回收临时文件；关闭无关共享接入不取消所属任务。接收结果只保留到下一次传输或所属接入关闭，请及时保存。

原生独立窗口点击选择/保存文件会先返回主窗口，按提示再次点击；快捷指令列表、编辑和指令集管理均在当前独立窗口内完成。尚未升级的从机没有XMODEM能力，按钮保持禁用，需要升级执行端。

## Agent（现有 CLI / MCP / 认证 WS）

使用 `extension_capabilities` 查询所选电脑的 `tool=serial`，获取 `agentActions` 参数 schema；通过 `extension_call` 的 `action` 调用。目标必须为 `computer:local` 或 `computer:<nodeId>`。

| action | 必要参数 | 返回或语义 |
|---|---|---|
| config | 无 | defaults、remoteAllowed、formats、protocols、xmodem=true、xmodemMaxBytes、xmodemChunkBytes |
| ports | 无 | port/description/hwid/manufacturer/serialNumber/opened |
| open | port、requestId | sessionId、config、state、generation、writable、controller；可选串口参数 |
| status | sessionId | 当前输入权、代次、连接状态 |
| read | sessionId；可选 cursor/limit | 无损 base64 data、nextCursor、droppedBytes、hasMore |
| write | sessionId、generation、data | format=text/hex/base64；text 可选 encoding；`interCharDelayMs` 可选0～20，默认0；非零时相邻字符/字节间隔指定毫秒，单次最多2048字节；按原样发送，不追加换行。Agent需持有当前输入权 |
| control | sessionId、generation、operation | take/release，GUI优先 |
| close | sessionId | 释放当前接入，最后接入释放 COM |
| xmodem-start | sessionId、generation、requestId、direction | direction=send/receive，size（发送必填实际大小）、blockSize=128/1024、checksum=crc/checksum；返回xmodem.transferId，准备阶段独占 |
| xmodem-upload | sessionId、transferId、offset、data | 连续32KiB以内base64块，重复块内容必须一致 |
| xmodem-run | sessionId、transferId | 上传完整后启动，receive直接启动；重复调用不重新执行 |
| xmodem-status | sessionId、transferId | 查询原任务；read/status也带xmodem进度 |
| xmodem-download | sessionId、transferId | 仅成功接收可下载，offset/limit（至多32768），base64 data、nextOffset、eof |
| xmodem-cancel | sessionId、transferId | 取消所属任务，输入恢复后须用最新generation |

每次 `open` 使用新的 32 位十六进制 requestId，重复同一请求只返回同一接入；改变配置不能复用 requestId。CLI/MCP 薄客户端未指定时会生成 requestId，直接 WS 调用者必须自己生成。打开超时后用原 requestId 与原配置显式查询，不另开接入。write 的响应丢失或部分发送不能判断设备是否收到，禁止自动重发。

例如在 MCP 调用 `extension_call`：

```json
{"target":"computer:local","tool":"serial","action":"open","arguments":{"port":"COM3","baudrate":921600,"requestId":"0123456789abcdef0123456789abcdef"}}
```

随后使用返回的 sessionId、generation 发送：

```json
{"target":"computer:local","tool":"serial","action":"write","arguments":{"sessionId":"返回的ID","generation":"当前代次","format":"hex","data":"00 FF 41 0D 0A"}}
```

读取时逐页使用 nextCursor，不把 base64 当文本，不假定一个 read 对应一条回复。完整字节00..FF经base64无损往返。XMODEM任务同样使用base64分块文件，协议只在串口目标端执行；Agent沿用现有权限和独占限制，不能读取或取消GUI任务。

连接最多 8 个、接入最多 64 个，每连接历史最多 1 MiB，裁剪通过 droppedBytes 明确报告。单次写入最多 65536 字节；读取页最多 65536 字节。30 分钟无人读取/操作的连接回收；持续设备输出不会无限延长租约。

发送结果暂未确认时，窗口继续显示收到的输出，暂停新输入，不重发。收到对应的明确回执后恢复新输入；之前排队的输入不会补发。长时间仍未确认可关闭窗口后重新打开，并先检查设备实际状态再决定是否重新输入命令。
