# DevMux 3.2.2

本版调整操作提示与在线升级：提示不再反复弹窗遮挡界面，重启升级少一步确认，GitHub 不可达时也能从 Gitee 完成升级。插件、配置与数据格式完全兼容 3.2.1，无需迁移。

- 成功类提示不再弹窗：上传、下载、插件更新、快捷指令保存等成功后的提示全部静默，操作结果以界面自身状态为准。
- 失败、警告与信息类提示统一 3 秒后自动消失，不再长时间停留在右下角遮挡终端内容。
- 同一类提示只弹第一次，之后重复出现改为右下角小角标累计次数，悬停可看最新一条文案，点击清零；跨机中转的日志消费失败等周期性错误不再反复刷屏。
- 修正 `warn` 类型提示的图标与边框，统一按警告色显示。
- 点「立即重启升级」后直接关闭并安装，不再额外弹一次系统退出确认；普通关窗仍会确认。
- 升级完成后安装目录的 `BUILD-INFO.json` 与 `SHA256SUMS.txt` 同步为新版本；安装失败回滚时保持旧文件。
- 更新清单与安装包下载增加 Gitee 备份源：GitHub 连不上时自动按顺序回退到 Gitee 的同版本发行版。

升级前请退出旧版 DevMux，再替换原目录中的程序即可；devmux-data/、已装插件与凭据无需变动。

- 插件开发说明在「五分钟开始」之后补上 pack 的结果怎么用：安装、启用、打开入口的完整步骤与使用说明第十一章的链接，并说明 `dist/` 根目录的调试包与 `dist/plugin/` 官方随包产物的区别。
- README 的源码运行段明确源码运行的数据目录在仓库根，与发布版 `DevMux.exe` 同目录的 `devmux-data/` 是两套独立数据，已装插件与凭据不互通。

# DevMux 3.2.0

本版新增官方插件与主程序的在线升级能力：插件可以脱离主程序单独升级，主程序也能在有新版时自动检测并完成替换。插件、配置与数据格式完全兼容 3.1.8，无需迁移。

- 官方插件独立升级：插件管理新增「检查更新」「全部更新」与行内「更新」，按发布清单比较版本，下载对应插件包并校验 SHA-256 后自动停用、替换、重新启用。升级失败会退回上一版并保留备份，整个过程无需重启应用；第三方插件不进入这条通道。
- 主程序在线升级：启动后静默检测新版本，右上角卡片提示下载；下载完成校验通过后退出并替换程序文件，再自动重启。替换失败自动回滚旧版并保留升级结果提示；「跳过此版本」永久生效。
- 首次启动自动装载随包的四个官方插件（USB 继电器、DB 烧写、米家控制、eBPF 调试），不再需要手动导入，后续升级检测才有可比较的基线。
- 发布流程把四个官方插件包作为独立 Release 资产上传，客户端按清单里的名称、大小与 SHA-256 下载校验；下载地址支持通过环境变量配置镜像，默认走 GitHub Release。

升级前请退出旧版 DevMux，再替换原目录中的程序即可；devmux-data/、已装插件与凭据无需变动。从 3.2.0 起，后续版本可以直接在应用内完成升级。

# DevMux 3.1.8

本版修复跨机中转在两端系统时间不一致时请求全部失效的问题，并降低远程串口输入的回显延迟。插件、配置与数据格式完全兼容 3.1.7，无需任何迁移。

- 中转请求的有效期判定改为按两端心跳折算后的时间轴比较，不再直接比较两台电脑的绝对系统时间。此前从机时间偏快超过 30 秒（实测见过快 214 秒）就会让每条请求一落地即被判过期，设备全部不可用，而界面始终显示“已连接”。
- 建立连接时的握手顺带完成一次对时：用回执中的接收时刻与本地发送/收到时刻做一次往返计算，结果按对端缓存，5 分钟老化；偏差突变超过 5 秒立即跟随并计数，往回退的方向限速 50ms/秒，避免已过期的请求被重新判为有效。
- 连接信息里把「可达 / 可执行 / 时钟已同步」三层分开，并透出 `clockSkewMs`、`clockRttMs`、`clockSynced` 与测量时刻；测出偏差超过 5 秒时，连接说明会直接写出差多少秒、哪一端偏快。
- 建立连接与解除连接的请求不参与过期判定，避免“要先对时才能握手、要握手才能对时”的死锁；其余请求仍然严格 fail-closed，从机离线期间堆积的命令在恢复后照样不会执行。
- 共享目录读取去掉一次多余往返：直接读取代“先取长度再读”，只有读到空才回头取长度判断文件是否被归档重建。该改动对日志、终端与串口三类流同时生效。
- 远程串口输入的回显延迟（千兆共享目录、真串口回环、同配置实测）：p50 由 160ms 降至 101ms，p95 由 249ms 降至 145ms；每个字符的共享目录往返由 17 次降至 14 次。
- 勾选“本地回显”时，字符在写请求发出之前就显示，不再等一次中转往返；写入失败时在终端里明确标出“[输入未送达]”。

升级前请退出旧版 DevMux，再替换原目录中的程序即可；devmux-data/、已装插件与凭据无需变动。

跨机中转的时钟修复**需要主从两端都升级**才完整生效：判定发生在接收端，只升级主控不解决从机时间不准的问题。时间偏差本来就不大的环境，只升级一端即可正常使用。

# DevMux 3.1.7

本版接入应用图标，并修复从机关闭后主控反复弹出离线拒绝提醒的问题。插件、配置与数据格式完全兼容 3.1.5，无需任何迁移。

- 应用图标接入 exe、窗口、任务栏与 favicon。
- 从机长时间离线时，后台回收旧终端与电脑终端接入不再每轮下发关闭请求，只在心跳恢复后继续回收，不再反复推送「不下发请求给离线从机」提醒。

- 中转错误提示按文案合并，心跳写入、设备枚举、会话读写等同类失败只保留一条，持续故障期间不再反复叠卡片。

升级前请退出旧版 DevMux，再替换原目录中的程序即可；devmux-data/、已装插件与凭据无需变动。

# DevMux 3.1.5

本版为内部结构重构，界面与功能不变，插件、配置与数据格式完全兼容 3.1.4，无需任何迁移。

- relay 一族收进 `relay/` 包：34 个 `relay_*` 模块保留原文件名与 `relay_` 前缀，调用方改走包门面，插件打桩点零漂移。

- 消息循环补兜底异常处理，缓存刷新机制加固，重复文件传输补校验。
- 新增静态审计工具（隐式全局、跨文件全局依赖、导入收敛校验），测试覆盖同步扩展：拖拽缩放断言、relay 全系用例照常通过。
